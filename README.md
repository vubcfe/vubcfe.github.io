# vubcfe.github.io

Personal academic website of Cao Vu Bui, built with [al-folio](https://github.com/alshedivat/al-folio) (MIT).

- Add publications to `_bibliography/papers.bib`
- Add projects to `_projects/`
- Edit the home page in `_pages/about.md` and the CV in `_data/cv.yml`

Pushing to `main` builds the site and publishes it through GitHub Actions.
